# AES Site Inspection

เว็บแอปเช็คลิสต์สำหรับ AE ของ ASTEC Engineering Service ใช้ออกตรวจหน้างาน บันทึกผลตรวจตามประเภทงาน วัดขนาดพื้นที่ แนบรูปพร้อมวาดชี้จุด แล้วส่งรายงานให้เซลหรืออัปโหลดลง Kanna

## ความสามารถ

- หน้าแรกเป็นหน้าสมัครใช้งานและเข้าสู่ระบบ ด้วย **ชื่อผู้ใช้ + รหัส 6 ตัว** การค้นหาประวัติงานตรวจของตัวเองต้องใช้ชื่อและรหัสให้ตรงกับที่สมัครไว้
- หน้าประวัติของแต่ละคน ค้นหาตามลูกค้า สถานที่ หรือเลข QT ได้ และทำสำเนางานตรวจเดิมเป็นแม่แบบได้
- ข้อมูลงาน: ลูกค้า สถานที่ วันเวลาทำงาน เอกสารที่ต้องใช้ การอบรม อุปกรณ์ Safety หน้างาน
- เพิ่มหมวดงานได้หลายหมวด และเพิ่มหมวดเดิมซ้ำได้หลายชุด (เช่น หลังคาอาคาร A / อาคาร B) มีหมวดกำหนดเองสำหรับงานที่ไม่มีในรายการ
- หัวข้อตรวจมีเลขข้อ พับ/เปิดรายละเอียดได้ แก้ชื่อหัวข้อได้ เพิ่มจุดย่อย (1.1, 1.2 …) เพิ่มหัวข้อเดียวกันซ้ำ และลบได้
- ผลตรวจ ปกติ / พบปัญหา / ไม่เกี่ยว พร้อมความเร่งด่วน หมายเหตุ และรูปในทุกข้อและจุดย่อย
- วัดปริมาณงาน กว้าง × ยาว × จำนวนจุด แยกระดับพื้นที่ (พื้น ชั้น Deck หลังคา) คำนวณยอดรวมอัตโนมัติ
- ถ่ายรูป วาดลูกศร วงกลม กรอบ ข้อความ และเขียนบันทึกใต้รูป
- ส่งออก: ข้อความสรุป (LINE / Kanna), รายงานเป็นไฟล์รูป JPG ทีละหน้า, รายงาน PDF และรูปถ่ายที่มีแถบคำอธิบาย
- สำรองข้อมูลของตัวเองเป็นไฟล์ .json (รวมรูป) และนำเข้าในเครื่องใหม่ได้

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML, CSS, JavaScript ในไฟล์เดียว) |
| `manifest.webmanifest` | ตั้งค่าให้ติดตั้งเป็นแอปบนหน้าจอโฮมได้ |
| `icon.svg`, `icon-192.png`, `icon-512.png` | ไอคอนแอป |
| `.nojekyll` | บอก GitHub Pages ให้เผยแพร่ไฟล์ตามที่เป็น |

## เปิดใช้งานด้วย GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repository (branch `main`)
2. ไปที่ **Settings > Pages**
3. หัวข้อ **Build and deployment** เลือก Source เป็น **Deploy from a branch**
4. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ-repo>/`

### ใช้โดเมนของบริษัท (ไม่บังคับ)

1. ใน **Settings > Pages > Custom domain** ใส่ เช่น `inspection.asteces.co.th`
2. ที่ผู้ให้บริการ DNS เพิ่ม record ชนิด `CNAME` ชื่อ `inspection` ชี้ไปที่ `<ชื่อบัญชี>.github.io`
3. เมื่อ DNS ใช้งานได้ ติ๊ก **Enforce HTTPS**

## ติดตั้งบนมือถือ

- iPhone (Safari): ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
- Android (Chrome): เมนู ⋮ > ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก

## เรื่องข้อมูล

- บัญชีผู้ใช้ งานตรวจ และรูป เก็บใน IndexedDB ของเบราว์เซอร์บนเครื่องที่ใช้งานเท่านั้น ไม่ถูกส่งขึ้น GitHub หรือเซิร์ฟเวอร์ใด
- ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ตามไป ให้ใช้ “สำรองข้อมูลของฉัน” ในหน้าตั้งค่าบัญชีเป็นประจำ
- รหัส 6 ตัวเก็บเป็นค่าแฮช ใช้กันคนอื่นที่ใช้เครื่องเดียวกันเปิดดูประวัติ แต่ไม่ใช่ระบบรักษาความปลอดภัยระดับเซิร์ฟเวอร์ ถ้าลืมรหัสจะกู้คืนไม่ได้
- ต้องใช้อินเทอร์เน็ตตอนเปิดหน้า และตอนสร้าง PDF / ZIP (โหลดฟอนต์ Sarabun, jsPDF และ JSZip จาก CDN)

## การแก้ไขหัวข้อตรวจ

รายการหมวดงานและหัวข้อตรวจเริ่มต้นอยู่ในตัวแปร `CATS` ใน `index.html` ตัวเลือกของข้อมูลงาน (วันทำงาน เอกสาร การอบรม อุปกรณ์ Safety) อยู่ในตัวแปร `OPTS` และระดับพื้นที่อยู่ใน `LEVELS` แก้ไขแล้ว commit ขึ้น GitHub หน้าเว็บจะอัปเดตเองภายในไม่กี่นาที
